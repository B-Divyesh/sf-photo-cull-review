# Photo Cull Review demo

Open `/?demo=1` or choose **Try it with sample data** on the first screen.

The sample is a four-file family archive: one byte-identical picnic copy and two distinct sparkler frames grouped as a cautious burst suggestion. The review screen opens in this browser. All normal keep, review, undo, navigation, backup, and CSV actions work.

Demo state uses the separate IndexedDB database `photo-cull-review-demo`. Real work uses `photo-cull-review`; neither reads the other. **Reset demo** reseeds the sample. **Start for real** deletes the demo workspace before returning to the empty real workspace. The three hand-drawn sample previews are precached for offline use.
